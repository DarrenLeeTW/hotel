# Hotel Brand

A simple static website for showcasing a hotel brand. The site includes sections for an overview, services, image gallery, and contact information.

## Project Structure
- `index.html` – Main page containing the content and layout for the hotel website.
- `styles.css` – CSS styles for layout and design.
- `images/` – Directory for site images and placeholders.

## Usage
Open `index.html` in your web browser to view the site.
